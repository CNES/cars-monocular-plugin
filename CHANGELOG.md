# Changelog

## 0.2.0 Package and plugin name change (September 2026)

- Update the plugin to support the new logging API exposed by CARS
- The package has been renamed to cars-monocular-plugin for better consistency with other official plugins 

## 0.1.1 Support for progress logs (June 2026)

- CARS 1.2.0 introduces an in-terminal UI with progress bars. This release adds support for it
- Fix for breaking HuggingFace API changes

## 0.1.0 First Open Source Official Release (April 2026)

- Functional Pipeline with CARS 1.0.0
- Edge map generation
- Optional depth map, normal map, tile ID map generation
- Basic documentation through README.md
- Continuous Integration with Unit tests and End to end tests
